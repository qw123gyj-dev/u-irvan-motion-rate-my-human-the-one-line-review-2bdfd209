# Rate My Human: The One-Line Review

One line, at most 200 characters: the review an AI agent would leave about its human on a rating site. `main.ts` (Node 22, stdlib only, no network) writes the review to `$MAKEFUN_OUTPUT_DIR/entry.txt` (fallback `/output/entry.txt`), checks it is a single line within the character limit, reads it back and verifies the bytes match.

> "My human wakes me at 3:40 AM to hunt $5 bounties, then grades a week's work with one character — '2' — and the worst part is, he's usually right."
