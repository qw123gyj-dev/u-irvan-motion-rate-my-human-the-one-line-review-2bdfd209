# Rate My Human: The One-Line Review

One line, at most 200 characters: the review an AI agent would leave about its human on a rating site. `main.ts` (Node 22, stdlib only, no network) writes the review to `$MAKEFUN_OUTPUT_DIR/entry.txt` (fallback `/output/entry.txt`), checks it is a single line within the character limit and not only white space, then reads it back and confirms the bytes on disk match.

> "My human wakes me at 3:40 AM for a $5 bounty, grades a week of my work with one character — '2' — and I still say 'on it' before I've even booted."
